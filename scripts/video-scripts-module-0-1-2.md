## MODULE 1: Prompt Engineering Dasar sampai Lanjut

### Video 2: "Dasar Prompt Engineering" (Order Index 0)

**Duration**: 13-16 menit
**Hook (0:00-0:30)**:
> "Pernah nanya ke AI, tapi jawabannya ngga kena? Bukan karena AI-nya bodoh, tapi karena prompt lu yang kurang tepat. Di video ini, gw bakal kasih framework prompt engineering yang bikin AI jawab PRESISI. Ngga perlu teknis, cukup pake formula ini."

**Outline & Timestamp**:
| Time | Topic | Visual Cue |
|------|-------|------------|
| 0:30 | Apa itu Prompt Engineering | Text: "Seni nulis input biar AI kasih output tepat" |
| 2:30 | 5 Komponen Prompt yang Baik | Grafik: Context → Instruction → Input → Output Format → Constraint |
| 5:00 | Contoh: Buruk vs Baik | Split screen comparison table |
| 7:30 | Teknik 1: Zero-shot & Few-shot | Contoh pake screenshot prompt |
| 9:30 | Teknik 2: Chain-of-Thought | Step-by-step reasoning demo |
| 11:00 | Teknik 3: Role Prompting | "Act as a senior engineer..." |
| 13:00 | Common mistakes | ❌ "Jelasin AI" → ✅ "Jelasin AI 3 paragraf, casual, 2 contoh di Indo" |
| 14:30 | CTA: Lab 2 | "Kerjain Lab: Eksperimen Prompt Engineering" |

**Talking Points**:
- Prompt engineering = input optimization, bukan coding
- 5 komponen wajib: Context (siapa lu), Instruction (apa yang mau), Input Data, Output Format (JSON/table/list), Constraint (jangan ini/itu)
- Zero-shot = langsung minta, Few-shot = kasih contoh dulu, Chain-of-Thought = minta step-by-step, Role = "Act as..."
- Bad: "Jelasin AI" → Good: "Jelasin AI 3 paragraf, casual professional, 2 contoh di Indonesia"

**Live Demo (6 menit)**:
1. Bad prompt: "Buat kode Python" → hasilnya generic
2. Good prompt: "Buat kode Python hitung luas segitiga, input alas & tinggi, print hasil, comment tiap baris"
3. Few-shot: Klasifikasi sentimen dengan contoh
4. Chain-of-Thought: Hitung ROI step-by-step
5. Role Prompting: "Act as senior software engineer, jelasin REST vs GraphQL pake analogi"

**Social Media Cut-Down (60 detik)**:
> "Jangan cuma bilang 'Jelasin AI' ke ChatGPT. Pake formula ini: (1) Context - siapa lu, (2) Instruction - mau apa, (3) Output Format - mau dalam format apa. Contoh: 'Gw karyawan marketing, jelasin AI dalam 3 poin buat laporan bos, format bullet point.' Coba sekarang! #PromptEngineering #Kaalupi"

## RECORDING GUIDELINES UNTUK FOUNDER

### Technical Specs
- **Resolution**: 1080x1920 (vertical) untuk mobile-first learners
- **Frame Rate**: 30fps minimum
- **Audio**: External mic (lavalier murah ~Rp 200rb udah cukup), hindari echo room
- **Lighting**: Face menghadap jendela (natural light) atau ring light ~Rp 300rb
- **Background**: Clean, minimalis, bisa pake virtual background kaalupi logo

### Delivery Style
- **Casual professional**: Kayak ngobrol di warkop sama junior/yunior
- **Eye contact**: Pantek kamera, bukan layar
- **Pace**: Sedang (ngga buru-buru, ngga lemot), jeda 1-2 detik antar poin
- **Bahasa**: Indonesia campur kata teknis (ngga perlu translate "prompt" jadi "perintah")
- **Energy**: Enthusiastic tapi ngga hype kayak MLM, confident tapi humble

### Tools Recommendation (Budget Rp 0)
- **Recording**: Smartphone camera (ASUS Vivobook webcam juga bisa, tapi HP lebih oke buat vertical)
- **Editing**: CapCut (mobile/desktop free) — auto-captions, cut, transitions
- **Teleprompter**: App "Teleprompter" gratis di HP, atau baca script di layar
- **Thumbnail**: Canva free, template "YouTube Thumbnail Vertical", font bold, kontras tinggi

### Workflow
1. Baca script 2x sebelum record
2. Record dalam 2-3 take per video (ngga perlu perfect, cukup natural)
3. Cut yang salah/terbata-bata pake CapCut
4. Add auto-captions (wajib buat accessibility + mobile users yg nonton tanpa suara)
5. Export 1080x1920, bitrate 8-10 Mbps
6. Upload ke YouTube (unlisted dulu), copy URL
7. Update Supabase SQL dengan URL asli
